## ⚙️ Como Executar

Para visualizar e executar os códigos presentes neste repositório, você pode optar por uma das seguintes alternativas:

1.  **Google Colab:**
    *   Faça o download do arquivo `.ipynb`.
    *   Acesse o [Google Colab](https://colab.research.google.com/) e faça o upload do arquivo para executá-lo diretamente no navegador, sem necessidade de instalação local.

2.  **Ambiente Local (Jupyter/VS Code):**
    *   Certifique-se de ter o Python instalado em sua máquina.
    *   Instale o Jupyter Notebook via pip: `pip install notebook`.
    *   Clone este repositório e execute o comando `jupyter notebook` no terminal, navegando até a pasta do projeto para abrir o arquivo.
